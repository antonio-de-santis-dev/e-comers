# JHipster generated Docker-Compose configuration

## Usage

Launch all your infrastructure by running: `docker compose up -d`.

## Configured Docker services

### Service registry and configuration server:

- [JHipster Registry](http://localhost:8761)

### Applications and dependencies:

- apiGateway (gateway application)
- apiGateway's postgresql database
- msAdmin (microservice application)
- msAdmin's postgresql database
- msCatalogo (microservice application)
- msCatalogo's postgresql database
- msNotifiche (microservice application)
- msNotifiche's mongodb database
- msOrdini (microservice application)
- msOrdini's postgresql database
- msPagamenti (microservice application)
- msPagamenti's postgresql database
- msRecensioni (microservice application)
- msRecensioni's mongodb database
