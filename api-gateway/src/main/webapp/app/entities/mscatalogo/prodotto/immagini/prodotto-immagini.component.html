📖 Come funziona

1
Immagine di copertina

Viene mostrata nella card del prodotto nella lista e come prima immagine nel dettaglio. Formato consigliato: quadrato 800×800px.

2
Immagini carosello

Sono le immagini aggiuntive che appaiono come thumbnails in basso nella pagina dettaglio prodotto. Puoi aggiungerne quante vuoi.

3
Formato immagini

JPG o PNG, risoluzione almeno 400×400px. Le immagini vengono salvate nel database come file binari (non richiedono server di storage esterno).
